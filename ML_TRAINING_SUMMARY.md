# Machine Learning Model Training - Complete Summary

## Overview

I've successfully created a complete machine learning pipeline for vehicle anomaly detection. The system reads historical telemetry data, trains an anomaly detection model, and can predict unusual vehicle behavior in real-time.

## How It Works

### Step 1: Feature Normalization
```
StandardScaler transforms all features to:
• Mean = 0
• Standard Deviation = 1
• Uses z-score formula: (x - mean) / std_dev
```

### Step 2: Anomaly Detection
```
IsolationForest builds 100 decision trees:
• Each tree isolates data points recursively
• Anomalies require fewer splits to isolate
• Contamination = 0.01 (flags 1% as anomalies)
• Random State = 42 (reproducible)
```

### Step 3: Prediction
```
For each new data point:
• Input: 13-dimensional vehicle telemetry
• Normalize with fitted scaler
• Pass through forest of 100 trees
• Output: Prediction (1=normal, -1=anomaly)
• Output: Anomaly score (lower = more anomalous)
```

## Quick Start Guide

### Train Models (First Time)
```bash
python3 train_model.py
```
This creates:
- `vehicle_scaler.pkl`
- `vehicle_anomaly_model.pkl`

### Use Models for Prediction
```bash
python3 predict_anomalies.py
```
This generates:
- `anomaly_predictions.csv`
- `detected_anomalies.csv`

### Load Models in Python
```python
import joblib
import pandas as pd

# Load pre-trained models
scaler = joblib.load("vehicle_scaler.pkl")
model = joblib.load("vehicle_anomaly_model.pkl")

# Load new data
data = pd.read_csv("new_telemetry.csv")

# Predict
X_scaled = scaler.transform(data)
predictions = model.predict(X_scaled)
scores = model.score_samples(X_scaled)
```
